## How to distribute

- Give every student the PDF brief and the same Starter Notebook.
- Ask each student to select exactly one track and record the chosen dataset in the notebook.
- Share the Dataset Access Guide so that each student downloads data from the original source.
- Keep the editable DOCX for instructor-side changes.

## Important note about the ILRI track

The MELDATA catalogue reports 3,533 data points across the dataset and describes three disease-specific workbooks (CBPP, FMD and LSD). Its public description does not provide per-workbook class counts. Students must inspect the selected workbook and report its exact positive/negative class distribution before modelling. Do not pre-assign a disease file based on an assumed class balance.

## Presentation

15 minutes total: 12 minutes for the presentation and 3 minutes for technical questions. The completed notebook is the technical record; slides should communicate the decisions, results and limitations.
