# Introduction au Machine Learning

**Statut : contenu prêt (slides + notebooks).**

## Objectifs

- Comprendre le changement de paradigme : programmation classique → apprentissage à partir de données
- Connaître le vocabulaire de base : feature, target, modèle, paramètres/hyperparamètres, train/val/test
- Distinguer supervisé (régression/classification) / non-supervisé / renforcement
- Être opérationnel sur l'environnement : Colab, repo `formation-ml`, premier notebook exécuté
- Avoir manipulé un premier dataset réel (California Housing) sans encore modéliser

## Plan de séance (2h30 / 150 min)

| Phase | Durée | Contenu |
|---|---|---|
| Accueil & activation | 10 min | Tour de table rapide, attentes du module, lien avec le Python déjà acquis |
| Bloc 0 — Foundations | 15 min | Donnée/variable/feature/target, représentation tabulaire, espace des features (intuition visuelle) |
| Bloc 1 — Qu'est-ce que le ML | 35 min | Programmation classique vs apprentissage, supervisé/non-supervisé/renforcement, régression vs classification, hypothèse/modèle/paramètres/hyperparamètres, train/val/test, généralisation (intuition) |
| Pause | 5 min | — |
| Setup technique | 15 min | Ouverture Colab depuis GitHub, copie dans Drive, tour du repo `formation-ml`, test collectif d'exécution de cellule |
| Démonstration — premier contact avec les données | 20 min | Exploration guidée de California Housing : colonnes, types, distribution du prix, nuage de points prix vs revenu médian ; question ouverte "comment deviner un prix sans modèle ?" |
| TP guidé | 35 min | Exploration autonome de California Housing (stats descriptives + 1 visualisation au choix), pas de modélisation |
| Débrief | 10 min | Retour sur les observations du groupe, reformulation "features → fonction → target", pont vers S2 |
| Évaluation rapide | 5 min | 2-3 questions Mentimeter sur le vocabulaire de la séance |
